# 案例试跑

## Jenny Hoyos 的快餐计时 Shorts

开场把「快餐」的承诺变成一个看得见的比较：买到和自己做哪个更快。原片的过程线是食材准备、汉堡烹调以及队伍推进，结尾的证据是时间和结果。下表使用 TED 演讲的时间戳定位她亲自讲解的片段。 [Shorts 原片](https://www.youtube.com/shorts/Jx5CxOLZlqQ) · [TED 讲解](https://www.youtube.com/watch?v=ZmNpeXTj2c4)

| 段落 | 看得见的证据 | 在文稿里的工作 |
| --- | --- | --- |
| 00:41–01:09 | 画面摆出两种获得快餐的方式。 | 抛出一个观众能猜答案、又能看到验证的比较。 |
| 01:17–01:42 | 用准备汉堡所需的食材提示进度。 | 给不熟悉烹饪的观众一个可见的进度条。 |
| 01:42–02:30 | 队伍前进，自己做的汉堡还没熟。 | 两条进度线相互牵制，谁先完成重新变得不确定。 |
| 02:36–03:31 | 从快到达终点的悬念进入结果。 | 用可核对的结果回答首句，并收束故事。 |

可移植的是「同一目标、共同起点、两个可见进度、意外改变领先方、公开结果」。质性判断来自演讲和视频。能检验它的假设是：提前显示双边进度会帮助观众理解自己在等什么，实测时可比第一处引入进度前后的留存。

## Aprilynne Alter 的开场教程

标题承诺如何做出更有吸引力的 YouTube 开场。00:25 开始交付第一个原则，先定标题与缩略图。02:00 把大问题缩到一个明确任务，让开场前五秒确认题面。03:39 讲后续开场要怎么安排。07:48 把原则转成可拍可剪的步骤。她在复盘里说，选题来自上一条视频里表现突出的开场段和观众反馈。这给出了选题依据，无法独立衡量各段对播放表现的贡献。 [教程原片](https://www.youtube.com/watch?v=TOHQXdCAo5k) · [选题复盘](https://www.youtube.com/watch?v=FVZQr7Jr8V0&t=323s)

可移植的是「标题先提出一个能解决的问题，片头用具体画面证明跟题，先给第一条可用信息，再补背景，最后交付可以立刻照着做的演示」。例如做成长教程，可以在前五秒直接放出修改前后的文稿读法，正片逐段解释改变，结尾给一张用来改首句的对照表。

## 迁移试写｜两种方法找照片，谁更快

**适用假设**：拍一支约 35 秒的 Shorts，受众是相册存了很多照片、会在聊天时临时找图的人。素材由拍摄者自备，时间来自实测。事先记下目标照片所在月份和可搜索词，随机安排出场顺序，固定同一部手机和同一起点。一次实测只说明这一次结果。

**候选开场 A**：「这张照片在三年前。用相册搜索和用日期翻，哪个先找到？」首帧放两台计时视图或同一手机的双路录屏。

**候选开场 B**：「你在聊天里急着找一张旧照片。这两个入口，我各试一次。」首帧放目标照片的模糊预览及两个入口。

| 时间预算 | 口播｜采用开场 A | 画面与兑现 |
| --- | --- | --- |
| 0–5 秒 | 这张照片在三年前。用相册搜索和用日期翻，哪个先找到？ | 目标预览与两个入口一起出现。 |
| 5–12 秒 | 都从相册首页开始。左边输关键词，右边直接定位月份。 | 双路录屏同时显示计时位。 |
| 12–26 秒 | 这里加一句描述本次实测实际发生的障碍或进度变化。 | 保留有信息的操作，明确标记跳剪。 |
| 26–35 秒 | 搜索用了〔实测秒数〕，按日期翻用了〔实测秒数〕。这张图先被〔实测方法〕找到。 | 展示结果和找到的同一张照片。打平则显示差距，并报告两种方式都找到了。 |

先测试 A、B 的首句与画面组合，使用相同正文、时长和结尾，记录停下观看比例和首段留存。若要知道是首句还是首帧影响结果，再做一次只改其中一个元素的对照。
