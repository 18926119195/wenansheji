# 公众号文案策划复盘

用文章原有的标题、语序、人称、断行和例子回推策划决定。任务是拆解已写原稿时，交付原文证据与设计过程。用户另要新稿时，再按用户给定的载体和目标成稿。

1. 核对输入中独立文章的数量、重复、署名和原有顺序。仅有粘贴文本时，用标题和紧随其后的文字分析入口。图片内容和原版实际首屏由材料决定。
2. 先读题目与题下几行，写出读者为何此时点开、会提出哪个问题、正文何时承认这个问题。定位第一次实质回应。摘要、倒计时、体裁提示或标题里的限制词可能承担不同工作。
3. 按原文顺序给关键段落标出短引、此时读者的问题、这一段增加的信息和下一段的起因。检查同一句式反复出现时改变了什么。逐行的停顿、代词转换、重复意象和单独成行的转折值得说明。
4. 回读结尾。看它给了判断边界、情绪出口、证据、规则还是入口。追踪最早出现的意象与最后一次出现之间发生了什么变化，把设计收益写到原句上。
5. 每篇保留最有信息量的两三个取舍。比如先给典故能累积情绪，晚一点给限定增加误解空间。对数字、收入、业务经历和效果分清可核验材料、作者自述、本文推断。没有作者当年的草稿、访谈或后台时，以成稿顺序描述可回推的设计。
6. 对多篇比较同一个问题在不同写作目标下如何回答。用真实坐标展示实践，文案语言贴合拟阅读它的面试官或编辑。
