# 文案策划与批量改写

根据用户实际发布的载体工作。公众号、笔记或文章用标题、摘要、首屏和正文来交付。明确要求视频时再做口播与画面。资料缺失时写明影响策划的假设，先给出可用稿。

## 从原稿到选题

1. 读完输入，辨认重复稿和不同稿件。定位原稿首次回应标题的位置，并用短句、段落名或时间戳找出推进、转折和兑现。在只有文本时，传播表现和受众反应记为假设。
2. 写出读者、阅读发生的具体时刻和读完能得到的东西。给同一题材拟来自不同阅读理由的候选标题。挑与素材最贴合的一条，记录一个实质取舍。例如扩大到就业回报需要额外证据，聚焦一张模考卷就能让读者立刻试用。
3. 先定末尾能交付的句子、例子、答案或工具，再倒排开头和中段。开头尽早确认标题承诺，并给第一处新信息。逐段标出读者此刻还想知道什么，合并同作用的并列段，给抽象结论补一个可验证的细节。

## 从策划到成稿

1. 给出实际可读的完整文案。根据交付场景附摘要、首屏、段落大纲或短图文变体。案例引用和编辑作品要能对应到原稿位置，实例、数字和身份陈述要对应到可核查的材料。演绎例子用清晰的示例语境承接。
2. 批量生成时，从原稿提取可替换的变量。换对象、场景、证据和话语，做出每篇自己的点击理由与交付。要展现策划能力时，保留被放弃的选题、关键改稿前后和核实过的材料，让作品呈现决策。
3. 按目标选发布验证。文章标题可测读者预期与打开，正文可测能否复述或照做，转化稿可测有效提交。对照固定其它条件并记录样本。既有表现、编辑核查和拟做测试各自写清。
4. 需要口播时，把首段承诺对应到首帧和第一句，逐段标画面与时长。语言通俗程度以实际目标读者理解为准。

用[策划及检验模板](references/analysis-template.md)选择需要的交付项。方法出处见 [Jenny Hoyos](../../../research/jenny-hoyos.md) 和 [Aprilynne Alter](../../../research/aprilynne-alter.md)。图文迁移见[作品集的模考案例](../../../portfolio/gaokao.md)。
