# 策划及检验模板

按用户要求选择字段。作品集可供招聘者先读成稿，再查支撑策划决定的证据。

| 环节 | 交付内容 |
| --- | --- |
| 立项 | 写给谁、什么时候看到、题材具体到哪个问题、文末交什么。 |
| 原稿批注 | 原稿位置和短引、它让读者期待什么、保留或改动的理由。 |
| 标题取舍 | 两到三种不同阅读理由对应的候选，同一句换词属于一组。选择和放弃的理由落在读者、证据与交付。 |
| 同一承诺 | 单看标题期待什么；只读摘要和首屏可否说清这篇交付什么。 |
| 正文 | 逐段检查新增信息。优先给一条能用的判断或一个实例，再在读者需要时解释背景。用例子、解释或动作推动下一个问题。 |
| 结尾 | 给答案、复盘卡、替换句、试作业或其它与题目相符的成果。让读者能执行，并留出反馈路径。 |
| 改稿记录 | 原句或原位置、改成什么、为什么。附已校验的口径、引用、关键术语或示例逻辑。 |
| 变体 | 给出不同题材的实际标题、首屏、进展和结尾。每次应用带一个新例子。 |
| 发布验证 | 记录版本、控制条件、渠道、分母、实际读数和下一步。测试前写假设。 |

## 参考动作

- Aprilynne Alter 的标题与开头确认可用于标题、摘要与正文首屏，早交付减少读者猜测。 [确认标题承诺](https://www.youtube.com/watch?v=TOHQXdCAo5k&t=120s) · [提前给出有用信息](https://www.youtube.com/watch?v=eRWyf-oDdCI&t=380s)
- Jenny Hoyos 先定开头与结尾再填中间。迁移到图文时，先定义要交付的动作或答案，再让正文每段推动一次。 [写作次序](https://www.youtube.com/watch?v=As7abwNhG7Y&t=1434s) · [进展与兑现](https://www.youtube.com/watch?v=7eosJwqoDaY&t=477s)

长文按自然段或小节定位。短视频可以用秒数定位，并把阅读预期换成观看信号。文章用实际平台所能提供的指标，首屏理解和能否照做也可通过定稿前的小样验证。
