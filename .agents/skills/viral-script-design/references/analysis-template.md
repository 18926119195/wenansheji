# 公众号原稿复盘模板

优先写有原句可以支撑的发现。一次案例可以从文稿结构走到一个足够小的句子改动或断行设计。

| 位置 | 可用的问题 |
| --- | --- |
| 选题与触发点 | 在此刻会点开的是谁？文章把大议题缩到了哪一个眼前问题？ |
| 标题与入口 | 标题承诺什么？读者会把哪个词理解得更大？第一段如何确认，第一条有用回应何时出现？ |
| 段落推进 | 此段解决上段的什么问题？新增的是具体细节、理由、反例、情绪层次还是行动条件？为什么在这里出现？ |
| 一个小决定 | 抓一个代词、反复意象、断行、并列顺序或转折词。它改变了读者接下来怎样读？ |
| 兑现与取舍 | 最后回答了题目的什么部分？留下什么到后文或以后？这种时序让谁继续，也可能让谁误读？ |
| 核对 | 写清证据是原稿、可核实数据、作者自述还是对效果的推断。只有纯文字时，可以标句子在正文中的相对位置。 |

写出「原句及位置 → 此处读者的问题 → 这一步怎样起作用」。必要时在文末列重要论据的口径。比较多篇时，用同样的问题审视观点、情绪或招募各自的不同结尾。招聘作品集优先让分析与原文彼此可照应。
