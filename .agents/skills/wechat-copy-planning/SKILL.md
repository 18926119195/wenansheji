# 公众号爆款文案策划

让读者明白为什么点开、每次下滑能得到什么、读完可以怎么做。先确定本篇要推动的一个主要动作，再决定标题的力度、论据的密度和收尾的位置。

- 需要追溯创作者的方法、视频章节和图文对应关系时，读[来源与迁移笔记](references/source-notes.md)。
- 策划新稿、做编辑评审或拿旧稿做面试复盘时，读[策划与复盘工作表](references/planning-and-review.md)。

## 从读者当下的任务定选题

把人群写到可以识别的场景里。说明他在什么时刻遇到问题、已经相信什么、接下来要做哪个判断。明确流量入口和一个主要目标，比如让陌生读者理解后转给同类、让已有读者找到表达自己处境的语言，或者让适合课程的人完成知情报名。

选题验证优先用真实提问、咨询记录、评论、历史同类文章和可核对的同类样本。检查样本表现相对于账号日常水平的变化，也记录节点、素材、分发和账号基盘。将观察写成可检验的假设。冷启动时可以围绕同一读者的相邻问题做小批内容，逐篇记录证据，及时删掉缺少材料支撑的题。

## 让入口与正文履行同一个承诺

先写一句“读完，读者能说清／做成什么”，再起草标题和末段。成套评估标题、封面或分享摘要、首屏和末段。标题给冲突或收益，封面提供辨认线索，摘要交代适用情境，首屏确认读者来对了并交付第一条有用信息。素材齐备时在手机上预览实际入口。旧稿只有纯文本时，根据现有标题和开头评审，补充设计标为推演。

有实质取舍时给两版入口，每版说明它会吸引谁、正文要补什么、可能给谁造成误读。争议型标题在摘要或首屏界定所批评的具体对象。教程和招募把决策必要信息放在读者会用到的位置。

## 排出段落之间的因果和回报

写下读者一路会问的几个问题。为每个主要段落标记“承接的问题、带来的新信息、下一段为什么需要出现”。叙事用新障碍和应对推进，论证用问题、后果、证据、解法推进。用具体情境解释抽象观点，给关键事实配来源，在有争议的地方放进最强反问。需要留悬念时，可以延后最后的重释，沿途交付例证、阶段性答案或可用动作。

在高密度论证后安放一个例子、短结论或可扫读的小标题。把视频中的画面提示迁移到正文中的例证、引用、图表或信息层级。需要读者跳读核对时，用标题、段首句和信息块让关键答案可定位。结尾回扣开头的承诺，按文章目标给一个相关动作。情绪稿可以收在一个可复述的句子上，报名稿则要在行动前明确适合谁、投入、关键规则和入口。

## 做可回查的复盘

先读原文，再顺着读者的动作复查。只看到转发卡片，他会以为这篇在说什么？第一屏答了哪一问？哪句让他接着读，哪句值得转给某个人？读到最后，他知道该点哪里或做什么吗？优先补看旧复盘跳过的那一步，用原句或行号来说。

用户要用自己的口吻时，挑原文几段看句子长短、人称什么时候变、抽象观点后面跟了什么场景。用这几项选择写新的复盘。允许短句、问句和行业常用说法，优先写“我会把哪一句挪到第一屏”“我会进后台查哪个数”。每节说清一个有用的决定。需要讲清取舍时，给一处可直接试的改稿或运营动作。

用原稿、署名和版本支持文本判断。当前拟写的标题和运营动作可以用“我现在会怎么做”来讲。写实际改稿经过、个人职责或发布成效时，回查草稿、协作记录或后台。

## 确定如何判断效果

按主要目标选指标。传播看同窗口阅读和分享，关系文可看分享及有效回应，招募看可归因的有效报名及后续参与。写出时间窗口、分母、入口、同类基准和可用数据。没有后台时报告可观察到的结构，给出下一步验证，并把具体效果留待核验。

交稿应足以让人复做一次策划，或让面试官沿着原文和数据追问一次具体决策。
