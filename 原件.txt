2024年5月11日  |  距离高考还有27天\

\
\
\
我希望每一个高中生、大学生，都务必务必看完这篇文章。\
\
我想从高考的“飞升文化”。\
\
我想从高考后的“学历贬值”。\
\
我想从高考前的“你永远能逆袭”。\

讲高考的三个骗局。\

\
\
\
图片\
\
\
“建国之后不许成精，1949年之后我们的国家就再没有出现过任何新的神话了。\
\

\
那就是高考。”\

图片\
\
\
\
\
对于一个古代普通人来说，只有两种选择：\
\
自己一生一世耕田。\
\
全家一生一世耕田，供你读书，考取功名。\

\

\
太多人为此献上注脚，从隋唐开始的上千年。\
\
几千几万几十万迁客骚人，不停地往上堆砌词汇意向，以证其确是通天入地的“鲤鱼龙门”。\

“朝为田舍郎，暮登天子堂。”\

“春风得意马蹄疾，一朝看尽长安花。”\

“范进中举，喜极而癫。”\

考上了，那就是门楣光耀，圣水镀金，以至于拥有了撒豆成兵的本领。\

奇幻仙侠小说，有渡劫飞升。\

普通人的现实生活，有高考上榜。\

“高考变成了一场审判”。\

你，985，211，你有未来。\

一定要说，我是做高考的，跟学历制度本是利益同盟。\

但对我而言，说假话不舒服，这样会让我恶心，我做不到。\

今天，我要做的事情，就是戳破高考的三个骗局。\
\
\
\
\
\
01\
\
高考，能让你飞升。\
\
\
\
\
\
高考完的人才知道，所有的考好了就好了，考好了就轻松了。\
\
都是假的。\
\
考好了之后，还有考好之后的人生，还要学校的期末考试，还要考研保研，甚至还有海外读博。\
\
研究生都已经五六百万人报考了，每年本科高中生才多少，也就1000万出头，这意味着什么？\
\
当研究生都普及的时候，研究生才是真正的“大学”。\
\
“高考”会变成初中，甚至大家的读书时间，会被默认为小学六年，初中三年，高中三年，大学四年，研究生三年。\
\
\
\
\
\
当高考之后，你还要卷研究生的时候，你就已经不能飞升了。\
\
当高考之后，你发现，你进入大学之后，你所有从考试里面获得的优越“985、211”，又因为你去到新的环境新的学校被完全拉平，咱们都是清华啊，咱们都是北大的，你又变得泯然众人，又需要再新的平台拼命努力，内卷证明自己，你的飞升被拉到一半，又回到地上了。\
\
当高考之后，你发现，原来高考也就只是一场考试，没有任何审判，没有什么点石成金，你只是用你自己的能力，换了一个小东西的，而你的能力：\
\
\
\
\
\
你幸福的能力，变开心的能力，情绪稳定的能力，找到男朋友女朋友的能力，让自己能呼朋唤友的能力。\
\
根本没有任何提升！\
\
它不能让你飞升，高考只能给你一个授权，学历的授权。\
\
而学历的授权，正在贬值。\

02\
\
学历是黄金。\
\
\
\
\
\
学历是铜锭的，只是表面有一层金。\
\
并且，学历铜锭上，这层表面的金，正在因为快速的时代变化而消解。\
\
\
\
\
\
所有人都觉得，随着科技的迭代和升级，翻译、会计会被最新取代，科技的发展还是很会给人制造惊喜的人。\
\
因为特么地大家都没有想过，人工智能，没过公司最新研发的GPT4.0，第一个威胁到居然是代码工程师，居然威胁到的是“互联网时代的天之骄子——程序员”。\
\
所有人都知道，志愿填报的时候，大多数学校，分数最高的专业，非计算机莫属。\
\
这个最红火的专业，居然受到了科技进步最大的挑战，很有可能是第一个暴毙的，尤其是“软件工程”。\
\
\
\
\
\
为什么学历贬值？\
\
\
\
因为科技的进步，暴露了“大学教育最大的鸡肋”，\
\
那就是“专业课程培养方案”和真正的“企业用人单位核心需求”出现巨大的错位和背离。\
\
也就是说：学校教学校的，在学校学知识。\
\
而在企业，需要你忘掉学校的知识，学习一套全新的东西。\
\
\
\
\
\
为什么学历会贬值？\
\
\
\
有个最本质的结论：价格是由供需关系决定的。\
\
全球经济下行，企业用工岗位需求减少。\
\
但普遍的大学扩招，却导致大学生遍地走，多如狗。\
\
这才是学历贬值的根本原因。\
\
\
\
\
\
正是这些种种的信息差，没有被补齐。\
\
才导致，每个高中生在高中的时候，在高考的时候，都把高考当神礼拜致敬。\
\
才导致了，甚至每个人都会刻意地给自己制造：永远能逆袭的骗局，无限的自我安慰，甚至是在高考只有四五十天的时候。\
\
\
\
\
\
03\
\
你永远能逆袭。\
\
\
\
\
\
你如果真的把高考当成神。\
\
大概率是：你永远不能逆袭。\
\
很简单，你是跪着的，对你而言，像神一样决定你命运的高考。\
\
神秘不可看透，你甚至都不敢睁开眼睛看一看。\
\
你都不知道自己干的是谁，你当然就只有被干死的结局。\
\
\
\
\
\
你的对手有无限的不确定性，你把你的对手无限的神化，那你必然无限无穷的弱势。\
\
你凭什么能逆袭？\
\
\
\
\
\
逆袭靠什么啊？\
\
心智得强。\
\
心里得信啊。\
\
你他妈跪在那里，两条大腿一直在抖，你逆袭个锤子。\
\
站起来，看清楚，站起来，看着高考，看看你面前的神佛，是不是正在跌落神坛。\
\
有什么锤子好怕的！草！\
\
怕个毛， 你焦虑个毛，八十天你焦虑个毛，就算真的没有考好，那又怎样！？？\
\
\
\
\
\
但我还是想说，我讲真相，但不反智。\
\
\
\
\
\
学历只是贬值了，不是没用了，它依旧是这个国家最重要的人才筛选工具。\
\
高考依旧还是在这个国家，最有权威的授权。\
\
限定了很多行业的准入门槛，当医生必然需要医学院，考公考事业单位必须要本科生、研究生。\
\
高考依旧是，最普遍，最大众，最公平的阶级上升的核心通道。\
\
只是规则稍微有了点变化，以前只要你有个学历，只要你考上985，211你必然就有好工作。\
\
不过现在的情况是，你除了学历的认证，你还需要拿得出手的能力。\
\
“能力+学历”的双认证，才是未来好工作的标配。\
\
\
\
\
\
\
\
\
\
如果你是高考生。\
\
记住：你还在这个时间，你只能做这个事情，你没有任何选择，你必须面对高考。\
\
你必须尽力去考，尽全力去考。\
\
\
\
\
\
也许时间真的不够了，也许逆袭的可能性确实在越来越少。\
\
你还是得去干，或许更重要的是，你需要在人生的某个时间段给自己证明：\
\
我有全力以赴的能力。\
\
让你人生的曲线，无限上扬，这才是你该做的事情了。\
\
在最糟糕的境地，担心害怕，像个反派一样说一句：事情变得有意思了。\
\
你才牛逼。\
\
\
\
\
\
\
\
\
\
我只是希望，人人不怕，人人不怨。\
\
我只是希望，每个人不被学历定义。\
\
以不被学历定义，不被学历审判的方式，以把学历当工具的方式，去追求学历。\
\
我认为没有问题。\
\
\
\
\
\
高中生，你要是真把高考当神，你才会怕。\
\
你跪在高考面前，你才会怕，才会瑟瑟发抖，才这么窝囊废物。\
\
\
\
\
\
曾经考好的大学生，你被高考授权过，985，211，清北，C9，没啥了不起的。\
\
你以为你真的牛逼了，你觉得有学历就够了，你才会懈怠自己的能力，你才会停止进步。\
\
\
\
\
\
曾经死在高考的人，你以为你真的被判废物终生，你才会自我暗示，自我洗脑。\
\
真正地去证明，这个无法审判人的高考，可以审判人。\
\
\
\
\
\
别跪在那里。\
\
给老子起来。\
\
干，\
\
给老子干！\
\
