# 公众号文案策划作品集

三篇原稿，三个写作任务。作品集沿着原文的顺序，拆解标题怎样让人点开、正文怎样推进、结尾怎样兑现。每个判断都能在原稿里找到对应的句子。

**[进入作品集](portfolio/README.md)** · **[查看公众号策划方法](portfolio/methodology.md)**

## 案例

- [《我越来越觉得，高考是一场骗局》](portfolio/gaokao.md)　怎样让一个争议标题容纳有边界的观点。
- [《浪漫主义者，天然有自毁基因》](portfolio/romanticism.md)　怎样把情绪共鸣推进到关系与行动。
- [《IP觉醒营【筛选版】》](portfolio/ip-camp.md)　怎样用信息释放顺序筛选早期申请者。
