# 这三篇公众号稿，我回头拆一遍

标题能把人叫进来。进来之后呢？

有人只看第一屏，就要决定这事跟自己有没有关系。有人读到末尾，想把一句话发给朋友。还有人已经想报名，他只需要知道作业有多少、几点截止、从哪儿进。

这三篇，我就顺着读者的手指往下看。哪句让人停一下，哪段该往前提，发完回后台先看什么。

## 三篇旧稿

- **关系文。** 从“我手里写诗”写到“有人也会在你身后”。中间最该留的，是读者能认出自己的几个小场景。 [《浪漫主义者，天然有自毁基因》](cases/01-romanticism.md)
- **考前观点文。** 标题写“骗局”，读者又只剩 27 天备考。我最想查的是，点开第一屏的人会以为我在劝他做什么。 [《我越来越觉得，高考是一场骗局》](cases/02-gaokao.md)
- **课程招募文。** 有人提前找到这篇，有人要等正式介绍。哪批人现在能做决定？他看完知道该点哪里吗？ [《IP觉醒营【筛选版】》](cases/03-ip-camp.md)

## 面试时，我会先拿《高考》讲

> 这篇有个地方，我现在会改。标题已经写到“骗局”了，开头说会讲三件事，可是“接着好好考”要看到后半篇才明白。想想那个读者。晚自习课间，他在班群里刷到一张卡片。铃一响，他就得收手机。再发一遍，我会把“剩下的 27 天，能拿的分继续拿”提前。然后把标题和首屏拿给备考生看，问他读完觉得自己下一步该干什么。他的第一句回答，就能告诉我哪里还要改。

## 下次写稿也能用

定标题前，先写一句读者最后能带走什么。排正文时，每一段问一句“看到这儿，他还想问什么”。发稿前，拿手机走一遍。发完，关系文先看有多少人分享，观点文看留言里哪些话被复述了，招募文查从哪个入口来、谁报了名、谁交了第一次作业。
