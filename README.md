# 公众号文案策划作品集

我复盘公众号文案时会追三个问题。读者为什么在这个时刻点开？正文用什么一步步兑现标题？最后一句能让人怎么理解、怎么行动？这三篇分别用关系场景、考前倒计时和提前招募来回答。

## 三篇作品

| 作品 | 策划问题 | 最值得解释的策划决定 |
| --- | --- | --- |
| [《浪漫主义者，天然有自毁基因》](cases/01-romanticism.md) | 怎样让读者认出自己，愿意在被说中之后接着读？ | 先让当事人讲出委屈，用病床、忘带钥匙、无人回消息落到生活，最后从等待理解走向和人一起做事。 |
| [《我越来越觉得，高考是一场骗局》](cases/02-gaokao.md) | 能否在考前用强观点打开话题，同时给备考者清楚的行动判断？ | 三节依次拆解升学、学历和逆袭的许诺。“学历的授权”把第一节送进第二节，末段把注意力交还给备考者今天能做的事。 |
| [《IP觉醒营【筛选版】》](cases/03-ip-camp.md) | 如何让已有意愿的人听懂筛选、判断自己并完成报名？ | 用“为什么这次低调”解释招募机制，给首批和后续了解者各自的路径，再检查关键信息是否放在报名之前。 |

可从《高考》案例开始看。它把选题节点、标题的误读风险、正文的论证顺序和改稿取舍放在一条线上。每篇都附可回到原稿的段落链接。

## 面试时可以这样讲

> 我做文案复盘，先问读者读完应该能说清什么。《高考》里，我最在意标题和结尾有没有说同一件事。开场用考前倒计时和三个问题把人带进来，第一节最后把学历说成一种授权，第二节才能顺着讲这种授权的价值。结尾落到考生仍然可以继续全力准备。这个立场到后面才完整出现。如果重做，我会先在摘要说明讨论的范围，请备考生和大学生分别复述，再看他们接收到的是放弃备考，还是少一层恐惧、继续行动。《IP觉醒营》的问题又不同，我更关心读者是否理解要求、报名后是否愿意完成第一项任务。数据有了，我会用对应的分母和时间窗判断这篇完成了什么。
