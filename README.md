# 公众号文案策划作品集

我是树林同学。这里有三篇公众号成稿，分别写关系、考前观点和课程招募。我把自己做自媒体时总结的经验，和这三篇原稿放在一起，提炼成现在的策划 Skill，再用它重拆三篇。

我写稿时，大部分篇幅用来把事情讲清楚。到了需要转弯的那一句，情绪就要一下子起来。话说重了，后面得接得住。关系文给读者一句能带走的话，考前文把人带回今天还能做的事，招募文得把报名条件交代清楚。 [我的经验总结](experience.md)

## 三篇怎么读

| 作品 | 先看哪处 | 发稿时怎么用 |
| --- | --- | --- |
| [《浪漫主义者，天然有自毁基因》](cases/01-romanticism.md) | 从想被理解讲到愿意和人共事，为什么到末段才喊出“依旧浪漫，才牛逼” | 选哪些生活细节留下，怎么判断读者分享时带走了哪句话 |
| [《我越来越觉得，高考是一场骗局》](cases/02-gaokao.md) | 三段论证怎么接上“站起来”，以及什么时候要把备考这件事讲明白 | 怎么改班群里的标题和首屏，发前找谁试读、核对什么数字 |
| [《IP觉醒营【筛选版】》](cases/03-ip-camp.md) | 先交代旧热度怎么来的，再突然说“保持静默” | 给三种状态的读者写清下一步，发前走报名流程，发完查付款和首份作业 |

赶时间可以先读《高考》。标题起得猛，正文靠三段论证把话说清，随后把行动交回考生。如果想看我怎么考虑公众号招募和发完后的数据，直接读《IP觉醒营》。
