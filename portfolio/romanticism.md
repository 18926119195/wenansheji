# 浪漫主义者，怎么从旁观走到现场

**任务**｜把一篇以情绪共鸣见长的长图文改成情景短视频。主受众是在新环境里想和人有连接，却习惯先观望的年轻人。

**原稿**｜树林同学《浪漫主义者，天然有自毁基因》。标题用“浪漫”与“自毁”制造反差。正文更具体的问题是，一个人越希望被理解，为什么越可能把自己放在关系以外？最后的交付是从旁观和评价走向参与和合作。

## 原稿证据

| 位置 | 短句或场景 | 为什么有效，转成视频时怎样处理 |
| --- | --- | --- |
| 开头写诗 | “我手里写诗” | 短句构建了作者认同的自己，接上期待落空，形成内外反差。标题里的“基因”是修辞。口播让观众先认出一个动作。 |
| 现实打断 | 忘带钥匙，发出的消息没有回音 | 大道理突然落在钥匙和手机上，观众可以用自己的经历补完画面。原稿连续列举爱情、疾病、学业和工作，短视频选一个具体场景即可。 |
| 关系转折 | “你要主动”“用行动去证明” | 文章从说自己有多孤独，转到主动沟通和参与。读者终于知道能做什么。图文编辑可提前放这一转折，再让其他段落解释它。 |
| “幸福的源头”段 | “从评价变成沉浸” | 核心反转。以一次真实可观察的行为来兑现，比如在群里认领一件小事，交给同伴一个可用的结果。 |
| 结尾回扣 | “得躬身入局” | 由身份标签落到行为选择。“有人在身后”是情绪回响。把结尾拍成开始参与的动作，让结果仍由观众自己决定。 |

优先调整第一个行动出现的位置。原文多处重提失望、孤独和人际疏离，几段互换顺序仍能读通。改稿只留一条故事线：看到邀约，习惯划走，给出具体承诺，现场完成一件小事。情绪由动作产生，文案就能保留余味。

## 包装和口播

**标题**｜想被人理解，可以先从一件小事开始

**封面**｜「消息看完，你回了吗？」自制群聊界面，手指停在发送键上。

- **A · 自我矛盾**「我以前总想有人懂我。群里真有人喊我去帮忙，我却一次都没回。」
- **B · 场景先行**「群里问谁能来布展。我打了个‘我可以’，盯了半天，还是删了。」

主稿采用 B。手机界面和手部动作在第一秒就能承接台词，观众可以先观察，再决定是否认同。采用情景演绎，聊天界面和素材自制。

| 时间 | 口播 | 画面 |
| --- | --- | --- |
| 0–7 秒 | 群里问谁能来布展。我打了个“我可以”，盯了半天，还是删了。 | 自制聊天界面，打字、停顿、删除。 |
| 7–17 秒 | 我觉得自己去了也插不上话。结果那天，他们缺的是一个能提前十分钟来拍照的人。 | 消息往下滚，浮出具体任务。 |
| 17–28 秒 | 我又点开群，回了一句：“我能早点来，拍完把照片发给你们。”时间、能做什么，两个都说清楚。 | 写下消息并发出。画面切到把相机放进包里。 |
| 28–38 秒 | 到了现场，我还是有点紧张。可我知道自己要先做什么。我拍下了挂起来的第一张海报。 | 手持推进，拍下自制海报。用道具表现场景，同伴无需露脸。 |
| 38–45 秒 | 如果你也想参与，找一件真的感兴趣的小事，先认领一个你做得到的动作。 | 结尾留在照片回传界面。 |

首测只换首句，使用同一张聊天首帧和近似口播时长。主看首段留存，另问试看者“此刻你会怎么开口”，检查他们记住的是具体行动还是情绪判断。评论只记录可公开的行为信号。先比较能否复述一句具体邀约，再决定做同题材续集。实测待发布。
