# 内容策划作品集

**自媒体运营 · 文案策划**

三篇长图文，三个内容任务。每个案例从原稿的一句话出发，解释它如何建立期待，指出转成视频时要动哪里，再交付可拍口播和发布验证方案。

| 案例 | 策划判断 | 交付 |
| --- | --- | --- |
| [高考的边界](gaokao.md) | 用一个明确的「高考决定什么」接住争议标题，把愤怒落到高三生今天能做的事。 | 事实核验、两版开场、约 55 秒口播。 |
| [浪漫主义者，怎么从旁观走到现场](romanticism.md) | 用可观察的行为变化兑现情绪共鸣，把抽象的自我反省拍成一个具体场景。 | 情绪节点、两版开场、约 45 秒情景口播。 |
| [招生筛选如何让人愿意做第一步](ip-camp.md) | 保留任务筛选，公开参与成本和判断依据，把转化目标设到有效作业。 | 招生短视频、报名页顺序、转化漏斗。 |
| [从拆解到批量选题](production.md) | 换对象和场景，保留能解释的观看理由，带着假设发布。 | 三条跨题材脚本、首轮发布和复盘方案。 |

## 我怎么做取舍

- **先兑现观众点进来的理由。** 高考稿提前解释作者针对的是哪种许诺。情绪稿尽早让观众看见一个自己经历过的场景。招募稿先给任务和判断信息。
- **每段都要交付新东西。** 保留能解释、证明或推进情绪的句子。能用一张对照表、一次动作或一件成品说明的地方，直接给画面。
- **用数据决定下一轮改什么。** 观点稿看理解与留存，情绪稿看动作是否被记住，招募稿看有效提交。各案例均提供观察口径。
