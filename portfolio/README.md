## 代表作｜模考卷上的分，哪些还能拿回来？

一篇面向高三学生的公众号图文。文章从模考出分当天切入，把「这次考得怎么样」拆成能从错题里核对的迹象。读到最后，可以直接带走一张复盘卡。
