# 公众号文案策划作品集

三篇公众号原稿各有一个写作任务。高考稿说清一个判断，浪漫主义稿写出一层说不清的感受，IP 觉醒营稿让愿意参与的人走到报名入口。

| 原稿 | 可追踪的策划取舍 |
| --- | --- |
| [《我越来越觉得，高考是一场骗局》](gaokao.md) | 用倒计时把大观点放到眼前。让读者经历「神话、审判、站起来」，再补上学历的作用和继续备考的理由。 |
| [《浪漫主义者，天然有自毁基因》](romanticism.md) | 用写诗、没回音的消息和催交的 PPT，让读者先认出自己。把孤独的解释从世界转回人与人的距离。 |
| [《IP觉醒营【筛选版】》](ip-camp.md) | 先让读者意识到这一轮为何低调，再给他一个判断是否该报名的标准。把作业、截止规则、正式发布和入口放在不同阅读阶段。 |

每个案例都沿着原文顺序标出原句、读者此刻的问题、下一段为什么接在这里，以及这样安排会付出什么代价。原稿署名为树林同学。设计意图从成稿回溯，阅读效果属于可验证的推断。涉及人数、留存或收益时，另注明资料口径。

研究框架来自 Jenny Hoyos 和 Aprilynne Alter 的公开访谈及教程。方法页标明了出处，并以这三篇原稿验证迁移是否说得通。 [方法与三稿对照](methodology.md)
