# 从拆解到批量选题

目标是用三篇样稿提炼能继续写的机制，并做出三条新题材样片脚本。先决定结尾能给什么证据，再写让观众留下来的开场。

| 从原稿提取的机制 | 适用条件 | 何时改写 |
| --- | --- | --- |
| **改写被一次结果定义的故事**。身份判断 → 这个结果实际影响什么 → 一个能复查的下一步。 | 受众刚收到考试、面试或工作反馈，而且下一次能练。 | 如果受众眼下需要的是报考、录取等明确信息，先给事实和入口。 |
| **用动作兑现共鸣**。一个熟悉的犹豫 → 看得见的原因 → 一句可以发出去的话。 | 关系主张能落成双方可以回答的问题或一起做的事。 | 如果故事只能靠虚构别人态度推进，换成提问、合作邀请或现场动作来呈现。 |
| **用任务筛选意愿**。给出一份小样 → 讲清完成和使用规则 → 让读者自己决定是否行动。 | 行动目标是投稿、申请或报名，观众能在行动前理解成本和标准。 | 有收费或授权条件时，把确认文案放在提交前。 |

三篇都先借了读者熟悉的判断，再用反差吸引注意。把反差写成可见场景，能更早给到读者一个继续看的理由。这是下一批选题要验证的假设。

## 三条原创待拍稿

标注时长是制作预算。画面使用自制道具和模拟界面。

### G2 · 面试结束，先补哪一句？（约 30 秒）

| 段落 | 口播与画面 |
| --- | --- |
| 开场 | 「面试刚结束，还记得哪一问答到一半卡住了吗？」桌上放一张空白面试复盘卡。 |
| 推进 | 「把那道题写下来。比如面试官问，你改过一篇稿，先改了哪里，为什么？你可以拿一篇自己真的改过的稿，写清楚改了哪一句、为什么。」展示一张道具稿和两栏批注。 |
| 兑现 | 「现在只录一句：原稿的问题是什么，我改了哪里。下一场面试之前，再听一遍这段。」录音完成，画面显示复盘卡的两栏已填。 |

### R2 · 同事回“先放放”，下一句怎么问？（约 30 秒）

| 段落 | 口播与画面 |
| --- | --- |
| 开场 | 「方案发过去，同事回‘先放放’。你会回什么？」画面显示一句模拟的工作聊天。 |
| 推进 | 「我会先把看到的和猜到的写开。看到的是‘先放放’。猜到的是‘他对方案不满意’。这两句现在都摆在纸上。」用两张便签，一张是消息，另一张是解释。 |
| 兑现 | 「我会接着问：‘我周四前有时间改。你想我先补预算，还是等排期定了再对？’把你的下一个动作，说成对方能回答的问题。」画面停在邀约发出，保留对方作答的空间。 |

### I2 · 社群征稿，大家能交什么？（约 30 秒）

| 段落 | 口播与画面 |
| --- | --- |
| 开场 | 「如果社群要征一张桌面照，我会先给大家看一份合格投稿。」展示一张自制样例，上面是一只贴了标签的收纳盒。 |
| 推进 | 「一张照片，加一句话。比如‘我把最常用的线先贴上标签，伸手就能拿对。’照片里别带地址、工牌或其他个人信息。」示范剪裁并加一句说明。 |
| 兑现 | 「想投稿，先看页面写的用途。参与活动和允许公开展示，各自确认。看完，拍一张桌面小物，再写一句它解决了什么。」展示模拟须知及两个独立选项。 |

## 首轮怎么验证

| 稿件 | 比较什么 | 主要观察 | 下一步 |
| --- | --- | --- | --- |
| G2 | 首句直接点出“卡住的面试题”，或先问“面试结果怎么复盘”。 | 首段留存和试看者能否复述要录下的那句话。 | 留存或理解不足时，把复盘卡的一个栏目提到第一镜。 |
| R2 | 首句问“你会回什么”，或直接复述同事消息。 | 首段留存、答案示范段的流失。 | 如果中段掉点，压缩两张便签的解释，保留完整回应。 |
| I2 | 首句先说“示范”，或先给“一图一句”的明确要求。 | 每千次曝光的合格投稿数。用页内完成率排查步骤。 | 先看用户是否能判断图片要求及用途，再改报名页。 |

同一条的两版固定首帧、正文、字幕规格和发布窗口。能分流时优先同批对照。自然分发采用相同统计窗口，记录各版流量来源、样本规模与波动。首轮先回答“观众有没有理解开场承诺”。发布后按「稿件编号、开场版本、曝光、留存或转化、异常说明、下轮改动」回填。当前为策划样片。
