# 模考卷上的分，哪些还能拿回来？

模考出分那天，你可能先看总分，再翻班群找排名。数字都记住了，卷子反倒被折起来，压在书底下。等到晚上准备复习，脑子里还是那个问题：这一次考成这样，后面还有多少机会？

先把卷子拿出来。找一道你看见答案以后会说「这题我明明会」的题。今晚只需要弄明白一件事：你是在哪一步把这几分丢掉的？

## 一道看起来很熟的题，可能漏了两个字

拿一道示意题。求 x² 的最小值，题目给的范围是 **1 ≤ x ≤ 3**。看到平方，你顺手写了 0。对照解析才发现，x 等于 0 时根本进不了这个范围，最小值是 1。你在题旁边写了「审题不仔细」，然后翻过去订正下一道。

找到第一处写偏的地方。你把 0 代进去时，漏做了一件事：先看这个数能不能取到。题目里已经把要求写出来了，只是在你的草稿上没有留下任何痕迹。

所以，错题旁边可以这么写：「看到变量，先把它能取什么值圈出来。」这一句比「以后仔细」好检查。再拿到一道题，草稿纸上只有两种情况：你圈了，或者没圈。

## 有没有机会拿回来，看你卡在哪里

把那道题的答案盖住，从头做一次。写到第一处卡住的地方就停笔。

如果你漏了题目里的限制，就在题干旁留一个记号，下次先查这个位置。

如果条件都看了，却想不出第二步，就把“看到什么条件，想到哪种方法”连成一句话。写完用自己的话说一遍，看中间有没有一步其实是从答案抄过来的。

如果连答案为什么这么写都解释不清，先回课本找对应的定义或例题，把这一小块补完。它值得单留一个复习时段。把三种情况都塞进“粗心”，明天拿起卷子，你还是得重新猜该做什么。

时间只够做一题时，先选你能重新做通、又知道下次具体要检查哪儿的那道。

## 换一道题，检查一下

订正后的那道题做对了，有时只是因为你还记得答案。第二天，找一道用到同一个动作、题面有所变化的题。做完先看你想改的那一步发生了什么。

就拿前面的示意题来说。把范围换成 **−4 ≤ x ≤ −2**，仍然求 x² 的最小值。你在草稿上圈了范围，再发现离 0 最近的是 −2，最小值是 4。这次值得记下的是：你在计算前先查了限制，做到了卡上那一步。

不用把每道错题都抄得漂漂亮亮。拿一张便利贴，留这三行就够你开始做一次了。

> **我在哪一步开始做错**　＿＿＿＿  
> **下回碰到这类题，我先做什么**　＿＿＿＿  
> **明天用哪道题检查这一步**　＿＿＿＿

分数会影响你接下来可以选的路。等到要填志愿，认真看分数；等到要复习，把卷子翻开。今天先在第一行写下一处具体的错误。到明天，你就有一件事可以亲手检查。
